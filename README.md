# OMNI-FLUX ⚡

Real-time fractal shader visualizer built entirely with AI — one structured prompt, 283 seconds, zero manual coding.

![OMNI-FLUX](https://img.shields.io/badge/WebGL2-Fractal_Feedback-7C3AED?style=flat-square) ![React](https://img.shields.io/badge/React-19-61DAFB?style=flat-square) ![TypeScript](https://img.shields.io/badge/TypeScript-Strict-3178C6?style=flat-square)

## What is it?

OMNI-FLUX generates infinite fractal worlds using WebGL2 fragment shaders with ping-pong framebuffer feedback loops. Each frame feeds back into the next, creating evolving, organic visuals at 60fps.

## Features

- 🎨 **11 Cyberpunk Presets** — DEFAULT, CYBER_VOID, INFERNO, LIQUID_DREAM, HYPER_GLITCH, NEURAL_STORM, QUANTUM_FOAM, DEEP_OCEAN, SOLAR_FLARE, MATRIX_RAIN, AUDIO_PULSE
- 🎛️ **8 Real-time Parameters** — Feedback, Speed, Zoom, Complexity, Distortion, Color Shift, RGB Split, Brightness
- 🎙️ **Audio Reactive** — Microphone input maps to shader parameters via Web Audio API
- 🎬 **Video Recording** — Record WebM directly from canvas with one click
- 📸 **Screenshot Capture** — Export PNG from canvas
- ⌨️ **Keyboard Shortcuts** — Space (pause), S (screenshot), V (record), H (hide UI), 1-0 (presets), R (reset)
- 📱 **Mobile Support** — Pinch zoom, swipe to cycle presets
- ⚡ **60fps** — GPU-optimized render loop

## Tech Stack

- WebGL2 + GLSL fragment shaders
- React 19 + TypeScript (strict)
- Vite
- Web Audio API
- MediaRecorder API
