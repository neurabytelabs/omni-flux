## 📹 VİDEO KAYIT TALİMATLARI

### Gerekli Araç
**QuickTime Player** → File → New Screen Recording
Ya da **OBS** (daha iyi kalite için)

### Video 1: Preset Tour (30-45s) ⭐ EN ÖNEMLİ
1. OMNI-FLUX linkini aç (fullscreen olacak)
2. 3 saniye bekle (DEFAULT preset)
3. `H` tuşuna bas (HUD gizle — sadece fractal)
4. Her preset'e tıkla, 3 saniye bekle:
   DEFAULT → CYBER_VOID → INFERNO → LIQUID_DREAM → NEURAL_STORM → DEEP_OCEAN → SOLAR_FLARE → MATRIX_RAIN
5. Son: RND butonuna 2-3 kez bas (rastgele geçiş)
6. Kayıt bitir

### Video 2: Parameter Play (15-20s)
1. DEFAULT preset, HUD açık
2. FEEDBACK slider'ı sola çek (0.5) → sağa çek (0.99) — dramatik fark
3. COMPLEXITY'yi 0.8'e çek
4. COLORSHIFT'i 0'dan 6.28'e kaydır (gökkuşağı efekti)
5. RGBSPLIT'i 0.5'e çek (glitch efekti)

### Video 3: Audio Reactive (15s)
1. AUDIO_SYS bölümünü aç, toggle'ı ON yap
2. Spotify/YouTube'dan bir şarkı aç
3. Fractal'ın müziğe tepki vermesini kaydet

### Video 4: Build Story (30s)
1. AI Studio tab'ında code assistant panelini göster
2. İlk prompt'u scroll'la göster
3. "Ran for 283s, Edited 7 files" kısmını göster
4. Preview'a tıkla — fractal görünsün
5. Boom 💥

### Kayıt Ayarları
- **Çözünürlük:** 1080p minimum (2K ideal)
- **Format:** MP4 / MOV
- **FPS:** 30 (yeterli) veya 60 (ideal)
- **Ses:** Video 3 hariç sessiz
- **Süre:** Twitter max 2:20, ideal 15-45 saniye
- **Crop:** Sadece browser penceresi, menü çubukları hariç

### QuickTime ile Kayıt
1. QuickTime Player aç
2. File → New Screen Recording
3. Options → Record Selected Portion seç
4. Browser penceresini seç
5. Record tıkla
6. Bitince menü çubuğundaki ⏹ butonuna bas
7. File → Export As → 1080p
